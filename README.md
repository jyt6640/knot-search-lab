# Knot Search Lab

Knot 백엔드의 탐색 기능을 로컬에서 개선하고 비교 평가하는 실험 공간이다.
서버 API 호환을 기본 목표로 하며, 검증한 변경은 원래 Knot 백엔드에 통합한다.

## 로컬 실행

1. 로컬 전용 환경 설정을 .env.search-local로 준비한다. 실제 비밀값은 저장소에 포함하지 않는다.
2. Docker Desktop을 실행한 다음 docker compose up --build -d를 실행한다.
3. API: http://127.0.0.1:18087. PostgreSQL: 127.0.0.1:55441.

기존 프로젝트와 별도 Docker volume을 사용한다. 초기 DB에는 자동으로 v1.30 평가용 문서가
들어가지 않는다. 현재 로컬 volume에는 별도로 복사한 합성 Workspace 458과 문서 90개가 있다.
평가 어드민의 평가 결과·검수 기록과 v1.30 평가기 연결은 포함되지 않아 별도 설정이 필요하다.
LLM 서버가 Docker 외부에 있으면 컨테이너에서 접근 가능한 주소와 인증을 설정해야 한다.

팀 CI와 하네스 워크플로는 이 실험 저장소에 포함하지 않는다.
